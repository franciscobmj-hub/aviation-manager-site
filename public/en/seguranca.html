Security

Your data. Your operation. More control.

Authentication, HTTPS and credential-protection best practices are part of the platform deployment structure.

🔒

HTTPS

The production environment should operate entirely over encrypted connections.

◈

Backend credentials

Tokens, Client Secrets and API keys should never be exposed to the browser.

◎

Access control

Authentication and permissions should limit information access according to the user's profile.

OAuth

Google Calendar and Gmail with controlled permissions.

Use only the scopes required by the system and keep refresh tokens protected.

Calendar

calendar.events

Specific permission to create and update events.

Gmail

gmail.send

Permission intended for sending without requiring broad inbox access.

Identity

userinfo.email

Used to confirm the account associated with the integration.

Secret

Refresh Token

It must be stored securely and never appear in public code.
